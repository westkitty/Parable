# First-playable Human Gate (M2–M6) — about 30 minutes on the M1 MacBook Air

Not accepted until you play it. `npm --prefix game ci && npm --prefix game run dev`, Chrome. Mark ✅ / ❌ with a note.

| # | Check | How | ✅/❌ |
|---|---|---|---|
| V1 Village life | Twelve villagers visibly work: chop, haul, build, farm, fetch water, pray | Watch 3 minutes from the default view | |
| V2 Inspect | Hovering a villager shows a mood **and the act that caused it** | Throw one villager gently, heal another, read both bubbles | |
| V3 Injury and care | A villager hurt by a hard throw limps or lies up; others care for them | Throw one hard (not to death) | |
| V4 Wood → house | Logs you drop on the building site go into the house; it gets finished | Drop 3 logs on the site | |
| D1 Drought | The land visibly browns day by day; the fire on day 5 feels like a crisis | Let days pass (or play through) | |
| D2 End and restart | The year ends with a card that tells what happened; "Begin a new year" restarts | Reach day 10 | |
| M1 Rain | Waking the shrine with the bell stone, then tracing spiral + wave there, is discoverable and feels earned | Without reading the README first, if you can | |
| M2 Sanctuary | The painted wall teaches Sanctuary; the dome actually saves a house from fire | | |
| M3 Glyph stones | Each of the five stones' rituals is guessable from the stone and its place | Try at least two | |
| M4 Seven new gestures | V, line down, line up, line sideways, square, peak, triangle each cast what you meant | 3 tries each; note misfires | |
| M5 **False casts** | Ordinary mouse movement right after a spiral does NOT cast a line miracle by accident | Known risk: straight strokes in the 5.6 s armed window read as line finishers (~6% in the synthetic corpus) | |
