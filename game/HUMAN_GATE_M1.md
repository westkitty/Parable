# M1 Human Gate — 10 minutes on the M1 MacBook Air

M1 is **not accepted** until you play it. Run `npm --prefix game ci && npm --prefix game run dev` and open Chrome. Mark each item ✅ / ❌ with a note. This checklist is adapted from Godhood Gauntlet G1–G12.

| # | Check | How | ✅/❌ |
|---|---|---|---|
| G1 Embodiment | The hand feels like *your* hand, not a cursor | Move around for 30 s. Does it lead or lag? Is it readable at every zoom? | |
| G2 Camera cooperation | The camera goes where you mean | Wheel from the full valley down to Ilse's face and back. Left-drag pans like grabbing land. Middle-drag orbits. R resets | |
| G3 First-press pickup | A log comes up on the **first** right-press, every time | 10 tries, approaching from empty ground | |
| G4 Gentle placement | A slow release puts the log down where you meant | Carry a log and set it beside the woodpile | |
| G5 Intentional throw | Throw distance follows how hard you flick | Short flick, then a hard flick. Is the difference clear? | |
| G6 Grip readability | You can always tell what you are holding | Hold a log, Ilse, and a fireball | |
| G7 Safe cancel | Esc always drops gently, never throws | Press Esc mid-flick | |
| G8 Gesture feel | The spiral and then the zigzag feel natural and not fussy | 5 Fireballs. How many attempts did they take? Did any fire by accident? | |
| G9 Witness response | Ilse's reaction to fire reads as fear of *you* | Burn the grove while she is near it. Hover over her afterwards | |
| G10 Settler care | Picking Ilse up and setting her down feels gentle; throwing her feels like cruelty | Try both and read her bubble after each | |
| G11 Haul loop | Dropping a log on the meadow gets it hauled | Watch one full trip | |
| G12 Temple | Door → chamber → tablet → back feels like a place, not a menu | Save, burn something, Load | |
| Look | **Does this look like a sacred miniature?** | Look at golden hour, the temple, the grove before and after burning | |
| Perf | Smooth on the Air | Press F3 at the default view: median frame ≤ 16.7 ms, p95 ≤ 25 ms | |
