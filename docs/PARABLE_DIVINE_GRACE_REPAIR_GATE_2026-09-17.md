# Parable Divine Grace Repair Gate

**Date:** 2026-09-17
**Status:** Conditional. Use only after a Godhood Gauntlet checkpoint returns PARTIAL or FAIL and the failure is a bounded intention-vs-simulation mismatch.

## Principle

Parable may assist the player's intention invisibly when raw simulation produces clumsy interaction.

The goal is not realism. The goal is **divine competence without obvious auto-play**.

## Trigger

Do not implement Divine Grace speculatively.

A repair is allowed only when:
1. a specific Gauntlet checkpoint failed or was Almost;
2. the expectation gap is recorded;
3. the defect is reproducible enough to bound;
4. the smallest plausible assistance can be named;
5. the repair does not violate a Godhood Contract invariant.

## Allowed assistance classes

### DG-1 — Acquisition grace
Slight attraction or target persistence after intent is clear.

Use for:
- near-miss acquisition;
- target flicker;
- small pointer instability.

Must not:
- grab through obviously wrong targets;
- change which object the player clearly aimed at.

### DG-2 — Grip stabilization
Stabilize an established grip contact to prevent jitter or visual burial.

Must preserve:
- object-specific grip semantics;
- current-frame targeting independence;
- visible weight/lag differences.

### DG-3 — Placement grace
Create a low-velocity placement band that favors deliberate set-down over accidental throw.

Must not:
- erase meaningful throwing;
- turn every weak throw into a drop.

### DG-4 — Throw-intent filtering
Reject high-frequency mouse noise while preserving deliberate velocity and direction.

Must preserve:
- current unsmoothed targeting behavior;
- distinction between lob and hurl;
- player-caused momentum.

### DG-5 — Camera precision grace
Temporarily damp camera sensitivity or conflicting movement during precision manipulation.

Must not:
- lock the camera unexpectedly;
- create hidden mode changes the player cannot predict.

### DG-6 — Gesture tolerance
Permit reasonable spatial/timing variation once production gesture semantics exist.

Must not:
- make unrelated shapes cast miracles;
- fire destructive miracles on ambiguous recognition;
- optimize the obsolete clockwise-only placeholder semantics into permanence.

## One-repair rule

For a PARTIAL milestone:
- choose the earliest/highest-impact failed checkpoint;
- make one bounded repair;
- rerun automated/rendered checks in its impact radius;
- replay the same human checkpoint and any immediately adjacent affected checkpoints;
- stop.

Do not stack multiple feel tweaks before obtaining new evidence.

## Repair report

Every Divine Grace change must report:
- failed Gauntlet ID;
- expectation gap;
- changed files;
- exact assistance class;
- affected Godhood Contract invariant IDs;
- automated/rendered checks run;
- human recheck still required;
- rollback seam.

## Forbidden use

Do not invoke Divine Grace to:
- hide a broken input mapping;
- compensate for a wrong object ontology;
- bypass shrine/temple progression bugs;
- make current placeholder miracles production-correct;
- replace missing animation/art;
- paper over severe frame-rate/input-latency problems;
- force a PASS.
